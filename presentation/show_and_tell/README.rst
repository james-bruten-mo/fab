Toy Build System Show and Tell
##############################

This presentation was given in August 2026 to introduce colleagues
to the work being done on the toy build system.

It is a Jupyter notebook using the Bash kernel. The handy "run" script
provided will create a virtual environment and install Jupyter et al
therein. The presentation will then be launched in your browser.

GitHub may try to render the notebook but it doesn't understand the
shell kernel so it probably wont work.
